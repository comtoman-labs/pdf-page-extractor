# 📑 PDF Page Extractor (PDF 페이지 추출기)

**PDF Page Extractor**는 대용량 PDF 문서에서 원하는 페이지만 손쉽게 잘라내거나 낱장으로 분할할 수 있는 **PySide6 & pypdf 기반 경량 데스크톱 유틸리티**입니다.  

온라인 웹사이트(ilovepdf 등)에 중요한 문서나 계약서를 업로드할 필요 없이, **100% 오프라인 환경에서 원본 화질 손실 없이 안전하고 빠르게** 필요한 페이지만 추출할 수 있습니다.

---

## 🌟 주요 특징 및 차별점

### 1. 🔒 100% 로컬 오프라인 무손실(Lossless) 처리
* 인터넷 연결 없이 PC 내부에서만 동작하므로 **개인정보, 계약서, 회사 기밀문서도 안심하고 처리**할 수 있습니다.
* 렌더링된 이미지를 다시 저장하는 방식이 아닌, 원본 PDF 벡터 텍스트와 개체를 그대로 복사하여 **화질 저하 없이 원본 품질을 유지**합니다.

### 2. 🗂️ 3가지 강력한 페이지 추출 모드
* **📑 연속 범위 추출**: 시작 페이지부터 끝 페이지까지 구간 일괄 추출 (`[현재 페이지로]` 버튼으로 화면을 보며 원클릭 지정)
* **🎯 자유 페이지 지정**: `1, 3, 5-8, 12` 형식처럼 콤마(,)와 하이픈(-)을 혼합하여 원하는 페이지만 골라 단일 PDF로 추출
* **✂️ 낱장 전체 분할**: 문서의 모든 페이지(또는 지정 구간)를 1페이지짜리 독립된 PDF 파일(`문서_page_001.pdf`...)로 분할 저장

### 3. 🖼️ 모던 PDF 뷰어 내장 (PySide6 QtPdf)
* 무거운 외부 PDF 뷰어(Acrobat 등)를 켤 필요 없이, 프로그램 내에서 페이지를 선명하게 미리보며 작업할 수 있습니다.
* **📖 두쪽 보기 / 📄 한쪽 보기 (`Ctrl + D`)**: 실제 책처럼 두 페이지를 스크롤바 없이 가깝게 나란히 놓고 비교할 수 있는 듀얼 스프레드 뷰를 지원합니다.
* **화면 맞춤 (FitInView)**, **너비 맞춤 (FitToWidth)**, **실시간 확대/축소 (Zoom)** 지원

### 4. 🌓 다크 모드 / 라이트 모드 (Dark & Light Theme) 지원
* `ping-scanner` 프로젝트의 검증된 테마 엔진을 적용하여, **우측 상단 토글 버튼** 또는 **`F6` 단축키**로 언제든 눈이 편한 다크 모드와 화사한 라이트 모드를 전환할 수 있습니다.
* Windows 시스템 테마를 자동으로 감지하며, 마지막으로 설정한 테마가 영구 보존됩니다.

### 5. 🖱️ 슬림 통합 컨트롤 바 및 편리한 UX
* **하단 단일 바 레이아웃**: 기존의 넓은 탭시트를 콤보박스 연동형 한 줄 컨트롤 바로 일원화하여 **PDF 뷰어 세로 화면을 대폭 확장**했습니다.
* **드래그 앤 드롭(Drag & Drop)**: 윈도우 탐색기에서 PDF 파일을 프로그램 창으로 바로 끌어다 놓으면 즉시 열립니다.
* **실시간 계산 및 검증**: 선택된 총 페이지 수 실시간 계산 및 직관적인 오류 방지(페이지 초과, 시작>끝 검증)

## ⌨️ 단축키 안내

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + O`** | PDF 파일 열기 대화상자 호출 |
| **`Ctrl + S`** | 현재 활성화된 탭의 설정으로 페이지 저장/추출 |
| **`Ctrl + D`** | 한쪽 보기 / 두쪽 보기(스프레드 뷰) 토글 |
| **`F6`** | 다크 모드 / 라이트 모드 테마 전환 토글 |
| **`←`** 또는 **`PgUp`** | 이전 페이지로 이동 |
| **`→`** 또는 **`PgDown`** | 다음 페이지로 이동 |
| **`Home`** | 첫 번째 페이지로 이동 |
| **`End`** | 마지막 페이지로 이동 |
| **`Ctrl + +` / `Ctrl + =`** | 화면 확대 |
| **`Ctrl + -`** | 화면 축소 |
| **`Ctrl + 0`** | 창 크기에 맞게 전체 화면 맞춤 |
| **`F1`** | 도움말 창 표시 |

## 🚀 실행 및 빌드 방법

### 1. 개발 및 일반 실행
가상환경 활성화 후 실행하거나 **`run.bat`** 파일을 더블 클릭합니다:
```bash
# 의존성 설치
pip install -r requirements.txt

# 실행
python main.py
```

### 2. 독립 실행 파일 (.exe) 빌드
**`build_exe.bat`** 파일을 실행하면 자동으로 PyInstaller를 통해 포터블 실행 파일이 생성됩니다:
* 빌드 결과: `dist/PdfPageExtractor.exe` (단일 단독 실행 파일)
* 파이썬이나 기타 라이브러리가 설치되지 않은 다른 PC에서도 이 파일 하나만으로 즉시 실행 가능합니다.
* **배포 권장**: 소스 코드에는 `.exe`를 커밋하지 않고, GitHub 저장소의 **Releases** 탭에 첨부하여 배포합니다.
